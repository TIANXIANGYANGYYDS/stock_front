# 活跃股速览：把展示改为可操作的行情比较

原有 3D 全景需要旋转或悬停才能读到股票信息，缺少明确的比较依据和筛选流程。本次将入口改为「活跃股速览」，默认呈现直接可读的行情对比，3D 探索由用户主动开启。

## 用户可以完成的操作

- 打开即看到样本的上涨、下跌、平盘及数据缺失数量。点击上涨或下跌即可筛选。
- 点击样本涨幅 / 跌幅首位，自动清除搜索及筛选、切换对应排序，并选中该股票。
- 按成交额、涨幅、跌幅或涨跌幅绝对值排序；组合名称 / 代码搜索、方向过滤及 `|涨跌幅| ≥ 5%` 条件。
- 每行显示名称、代码、成交额排名、涨跌幅与成交额，使用相同刻度的条长辅助比较，并提供独立 K 线入口。
- 选中股票后，查看样本成交额排名、占比、样本涨跌幅中位数和相差的百分点，再进入决策工作台查看 K 线与策略。
- 手机端在选中行下方展开对比依据，保留有文字的顶部入口与滚动时可用的关闭按钮。

## 数据边界

继续使用 `getStockList(tradeDate, '', signal)`，读取指定交易日、前复权、成交额降序的前 50 只股票。不变更接口、原始行情字段或交易策略。

概况、排名、占比、中位数和可视化刻度始终基于完整已加载样本。搜索和筛选只改变展示对象，不改变比较基准。这些统计不代表全市场；页面明确展示交易日、样本范围以及个股数据日期。

成交额排名使用并列排名；占比以有效非负成交额合计为分母。涨跌幅中位数排除缺失值，零值保留。缺失数据展示 `--`，没有上涨 / 下跌股票时相应首位为空。成交额不解释为净流入，本页不生成买卖信号。

## 3D 的位置

默认列表不请求 `market-scene` 模块。主动进入 3D 后使用同一组筛选结果，柱体高度表达涨跌幅绝对值，标签同时显示名称、代码和真实涨跌幅。切换筛选时保持完整样本的高度刻度。WebGL 不可用或上下文丢失时可返回行情对比，继续查看与跳转。

## 验证

- 41 个测试文件、240 项测试通过，新增排序、5% 边界、组合搜索、缺失值、中位数、并列排名和固定样本分母的测试。
- 生产构建、项目类型检查和应用入口严格 TypeScript 检查通过。
- Chromium 连接真实后端验证 50 只股票、样本内搜索、排序、方向过滤、榜首定位、固定分母及跳转到匹配的 K 线；检查默认列表不加载 3D 模块。
- 320、390、720、959、1024、1280、1600px 检查列表和弹窗横向溢出、入口可见性、手机行内依据、Escape 焦点恢复。修复浏览器实测发现的网格行压缩重叠和窄屏模式按钮换行问题。
- 验证可选 3D 的筛选与标签、上下文丢失后的释放与返回、无 WebGL 环境、减少动态效果设置、手机关闭按钮和指令中心入口。
- 通过浏览器响应替换验证接口错误及重试、空日期数据、平盘 / 缺失分开显示以及无符合方向时不显示虚构榜首。上述异常数据仅用于测试。

真实接口核对示例：2026-09-04 快照中，50 只样本上涨 21 只、下跌 29 只；中际旭创成交额排名第 1，样本成交额占比 4.93%，涨跌幅 +0.12%，比样本涨跌幅中位数高 1.41 个百分点。此记录用于说明信息展示，界面使用接口返回值计算，不硬编码示例。
