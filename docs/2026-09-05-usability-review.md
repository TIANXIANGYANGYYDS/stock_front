# 交互体验审查

检查决策工作台、市场洞察、实时资讯、博主观点和量化影子盘，沿用现有深色终端、青色强调色、中文字体与红涨绿跌规则。

## 已处理

| 原有问题 | 调整 |
| --- | --- |
| 工作区导航仅修改组件状态，刷新或返回时页面不对应 | 用浏览器历史状态记录当前工作区，保留现有 `/`、`/quant` 路径 |
| 切换工作区后，个股、图表周期、筛选条件和量化策略丢失 | 在应用内保存用户选择，返回后恢复；离开的页面仍卸载并停止请求 |
| 输入股票关键词会自动换股，搜不到时清空正在看的图表 | 搜索只更新候选列表，点击结果或按 Enter 主动选股；支持清除与 Escape |
| 交易日、个股列表、K 线、板块排行、盘前分析、资讯请求失败后缺少恢复操作 | 在错误位置提供重试，不必刷新整个应用 |
| 资讯界面只显示 100 条，API 封装又只取后端第一页 | 读取完整日期窗口，完成后在本地筛选、排序及分页；翻页和排序无需重新下载 |
| 手机资讯详情在列表下方，点击后看不到变化 | 窄屏使用独立详情面板，提供返回按钮、Escape、焦点恢复和焦点约束 |
| 换一条资讯后正文沿用上一条的滚动位置 | 新资讯从正文顶部展示；分页和排序后列表回到顶部 |
| 新闻时间范围的“当天”容易被理解为电脑今天 | 筛选摘要明确显示所依据的交易日期 |
| 手机股票列表展开 50 行，把 K 线推到很远的位置 | 股票列表限高并独立滚动；主导航独占一行，指数与行情日期分行展示 |
| 板块选择只能再次点中原行才能取消 | 提供“显示全部板块”；排行行支持键盘 Enter / 空格 |
| 板块热度利好显示绿色，与终端其他位置相反 | 统一利好红色、利空绿色 |
| 正文中的“关键要点 / 关联标的”重复展示“不涉及板块” | 隐藏此类无内容的详情区块 |

## 第二轮：图表刷新与量化操作

| 原有问题 | 调整 |
| --- | --- |
| 日线图在实时价格更新时销毁并重建，历史位置和指标被重置 | 保留图表和副图实例，只更新数据；查看历史时保留对应日期，位于最新位置时随新增 K 线前移 |
| 通过拖动或“适配全部”改变范围后，“重置窗口”可能没反应 | 每次点击直接恢复最近 60 个交易日 |
| MA / BOLL 和副图开关在切股、切工作区后被覆盖 | 保存用户选择，当前股票没有对应指标时隐藏控件，有数据后沿用选择 |
| 全屏失败未处理，进入后按钮仍叫“全屏图表” | 提示失败状态，进入后显示“退出全屏” |
| 量化页面同样条件再次点击查询不发请求 | 明确触发重新查询；修改但未提交的筛选显示待生效提示 |
| 量化子页面切换丢失筛选、排序和页码 | 按策略和子页面保存选择，返回后恢复；不同策略分别保存 |
| 很多页只能连续点“下一页”；数据减少后停留在不存在的页 | 增加页码跳转及范围校验，刷新后自动回到有效页 |
| 信号撮合明细在后台刷新后自动收起，明细按钮键盘事件被表格行截获 | 同一条信号继续展开；按钮与表格行分别处理键盘操作 |
| 快速查询 / 切日期时，过时请求可能覆盖新结果 | 四类量化列表及历史日结果均丢弃已取消请求的返回 |
| 历史结果缺少“查看最新”入口，空状态显示内部值 latest | 增加“查看最新结果”，空状态使用可理解的中文 |
| 博主原文阅读每切一篇就跳回分析页，正文滚动位置沿用上一篇 | 保留原文 / 分析选项，新作品从顶部开始；固定详情栏隐藏无效的关闭按钮 |

## 使用边界

- 应用内的筛选和选择记忆持续到整页刷新；浏览器历史中的当前工作区可以在刷新后恢复。
- 资讯首次打开较大时间窗口时，需要读取该窗口的全部后端分页；切换日期或搜索时取消过时请求。筛选和排序覆盖已经完整加载的窗口，不把局部列表称作全量结果。
- 图表、行情来源及指标计算仍遵循现有后端契约。本轮未变更真实交易行为。
