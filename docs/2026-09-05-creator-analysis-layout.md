# 博主观点：以分析阅读为中心的布局

## 改版依据

原页面把评分榜放在左栏，作品流放在中栏，完整分析固定在 440px 的右栏；宽度不足 1281px 时分析被隐藏成弹层。摘要正文只有 11px，原始标题、统计卡片和重复标签占据了主要视觉位置。

本次调整页面的信息层级，沿用深色终端、青色强调色、中文无衬线字体、既有圆角及红涨绿跌规则。采用克制的布局变化和高可读性正文，不增加展示性动画或装饰图片。设计参数为布局变化 4、动效 1、信息密度 6。

## 新展示格局

- 桌面使用 320px 作品目录和自适应分析区，1440px 屏幕下分析区占主体约 76%。960–1125px 时目录收窄至 290px。
- 目录默认显示按时间排序的作品；主标题改用结构化观点预览，原始作品标题作为次级信息。博主排行放在同一区域的另一个页签。
- 当前作品默认展示重点分析。摘要使用独立强调区域和 18px 正文，随后展开逐条观点、立场、置信度、成立条件、衡量指标与验证说明。
- 多观点作品提供标的定位按钮。原文依据和有效期通过展开项核对，完整原文保留独立页签。
- 作者历史准确率与有效样本数随当前作品展示；无评分和少样本保留明确说明，不计算新的评分。
- 全局数量概览缩为一行辅助文字。搜索保持直接可用，平台和方向筛选按需展开，当前博主可以单独取消。
- 分析区提供上一篇、下一篇；目录自动让所选作品保持可见，原文 / 分析阅读选择沿用现有会话记忆。
- 960px 以下直接显示分析正文，作品目录改为按需打开的面板；手机进一步收起默认时间筛选和全局统计，为摘要腾出空间。

## 交互与数据边界

- 关闭目录后焦点回到打开按钮；在目录中选定作品后焦点进入当前分析区。支持 Escape 关闭目录。
- 分析、排行、作品列表保留独立加载与错误恢复。加载更多失败时，已打开的分析继续可读；重试后清除分页错误。
- 摘要、观点、条件和验证说明仍直接使用已有接口字段，没有新增预测或推导分析结论。
- 作品按时间排列，不把评分排行解释成作品重要性。方向筛选仍只覆盖已加载作品，界面明确注明这一范围。

## 验证

- 组件回归覆盖原文阅读模式、作者筛选、详情缓存、过时分页请求、窄屏直接阅读、目录焦点恢复、上一篇 / 下一篇与分页失败恢复。
- 使用真实接口检查多观点定位、原文展开、博主排行筛选、目录与分析切换。
- 实测 390、720、959、960、1024、1280、1440px 宽度；分析直接可见，页面无横向溢出。
- 全项目 39 个测试文件、220 项测试通过；生产构建和从 `App.tsx` 覆盖全部已接入页面的严格类型检查通过。
