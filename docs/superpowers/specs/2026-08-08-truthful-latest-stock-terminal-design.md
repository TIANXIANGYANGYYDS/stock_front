# Stock_Project 最新数据终端修正设计

## 目标

前端只展示 `Stock_Project` API 返回的最新行情及随行情返回的原始指标，不接入第三方行情、不补造样例、不在浏览器生成个股结论。修复 K 线交互时指标消失的问题。

## 数据边界

- 行情唯一来源为当前 Vite 代理下的 `/backend-api/api/v1/*`。
- 股票列表以 `/api/v1/stats` 的 `latest_trade_date` 和 `/api/v1/stocks` 为准；K 线以 `/api/v1/stocks/{code}/daily` 为准。
- `ma`、`macd`、`chip` 仅透传后端字段；缺失时明确显示“后端未返回”，不得在前端推导替代。
- 删除前端 `deriveTechnicalDecision` 及所有推荐、入场、止损、止盈字段和界面。
- 删除本地临时 Tencent 导入记录及导入脚本；删除未使用的硬编码个股推荐组件。

## 图表结构

- 图表创建与数据装载只依赖股票 K 线数据。
- 周期切换只更新可视区间，不销毁图表。
- MA 与成交量按钮只调用序列 `applyOptions({ visible })`，不销毁图表。
- MA5、MA10、MA20 序列读取每根日线随附的后端 `ma` 值；值缺失的日期跳过。
- 股票切换允许重新创建图表，组件卸载时统一清理。

## 右栏与文案

右栏改为“最新行情快照”，展示最新交易日、OHLC、涨跌幅、振幅、换手、成交额、成交量，以及后端 MA/MACD/筹码字段。底部固定声明“仅展示 Stock_Project 最新日线及随附指标，不生成个股结论”。

## 验收

- 单元测试证明日线映射保留后端指标，MA 图层只消费后端值。
- 切换 10/20/30 日、切换 MA、切换成交量、全屏后，已开启图层保持显示。
- 全仓测试、类型构建通过。
- 清理后本地数据库不再包含 `source.provider = "tencent"` 的临时记录；如果真实数据库为空，页面诚实显示空状态。
