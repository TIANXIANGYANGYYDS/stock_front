# 移除情报页面顶部横幅

## 目标

移除市场洞察、实时资讯和博主观点页面顶部占用空间的介绍横幅，让有效内容直接从页面顶部开始。

## 范围

- 市场洞察：删除英文标签、页面标题、说明文案、“主线追踪”和“最新评分”展示项。
- 实时资讯：删除英文标签、页面标题和说明文案；搜索框移入现有资讯筛选栏，搜索功能和占位文案不变。
- 博主观点：删除英文标签、页面标题、说明文案和账号同步状态/重试入口。该入口不迁移。

## 布局

- 删除三个页面组件中的整个 `view-heading` 节点。
- 资讯页网格从“标题 + 筛选 + 内容”改为“筛选 + 内容”，搜索框作为筛选栏的一部分。
- 博主页网格从“标题 + 概览 + 筛选 + 内容”改为“概览 + 筛选 + 内容”。
- 不改动下方内容组件、请求、筛选逻辑或响应式结构。

## 测试

- 断言三个页面不再渲染对应的 `view-heading` 节点。
- 断言资讯搜索框仍可用，但其父元素为下方的 `news-filter-bar`。
- 断言博主页仍渲染概览、筛选和工作区。
- 运行相关组件测试、全量单元测试、TypeScript 检查和生产构建。
