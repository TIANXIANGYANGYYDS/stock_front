# 行情盘后展示与日线/分钟线切换修订设计

## 已确认目标

本修订以用户 2026-08-11 的直接指令替代原设计中的“右栏实时快照”方案：

- 大盘指数和个股实时接口在盘后仍发起首次请求并展示接口返回的最后一笔成功行情；`market_status=closed` 仅停止 5 秒轮询，不清空数据，也不显示成请求错误。
- 删除 `DecisionPanel` 中新增的“实时行情 1m”快照区，恢复右栏只展示日线快照、筹码和技术指标。
- 主图原“近10日 / 近20日 / 近30日 / 近60日”入口改为“日线 / 分钟线”模式切换。
- 日线模式继续展示现有历史日 K、均线、指标、十字光标和导航。
- 分钟线模式只展示单股实时接口当前响应中、该股票最新交易日的分钟 K 数据；按 `timestamp` 排序和去重，不在浏览器累计、持久化或伪造分钟历史。
- 分钟线以接口 `open/high/low/close/volume` 绘制当日蜡烛图和成交量；若接口只返回一根分钟柱，则如实展示一根并给出轻量提示。

## 数据与状态

`DecisionWorkspace` 继续用批量实时接口更新左侧股票列表的最新 `close`，并用单股接口取得当前股票的全部 `items`。主图接收完整 `RealtimeStocksResponse`，而不是只接收第一条报价。

分钟数据选择规则：

1. 仅保留当前股票代码且 OHLC、`timestamp` 有效的项目。
2. 优先使用响应 `tradingDate`；若缺失，则使用最新有效项目的上海交易日期。
3. 仅保留该交易日项目；相同 `timestamp` 以后出现的项目覆盖以前项目。
4. 按时间升序绘制；最新价格使用最后一项的 `close`。
5. 不从分钟报价推算后端未提供的涨跌额或涨跌幅。

状态文案区分“加载中”“暂无当日分钟行情”“数据可能延迟”“已闭市 · 最后行情”和“交易中”。刷新失败时沿用轮询 hook 的最后一次成功响应。

## 组件边界

- `realtime-format.ts`：新增纯函数，筛选、去重并排序当前股票的一日分钟报价。
- `IntradayCandlestickChart.tsx`：只负责分钟蜡烛图和成交量，不包含请求逻辑。
- `ProfessionalCandlestickChart.tsx`：管理日线/分钟线模式、公共股票标题和状态；日线沿用现有实现，分钟线消费上述纯函数结果。
- `DecisionPanel.tsx`：移除实时快照 props 和 UI，保持日线数据真实性。
- `DecisionWorkspace.tsx`：把单股实时响应及状态传给主图，右栏不再消费实时报价。

## 验收

- 盘后成功响应的五个指数仍显示价格、涨跌额和涨跌幅，并标记“已闭市/最后行情”。
- 日线/分钟线可点击切换；分钟线只包含一个交易日、时间轴显示时分。
- 分钟接口多项、乱序、重复时间、空值和单项响应均有测试。
- 右栏不存在“实时行情 1m”区，原日线、筹码和指标不回归。
- 轮询保持首次立即、开市 5 秒、闭市停止、聚焦/恢复可见刷新、无并发和失败保留旧数据。
- 完整 Vitest 与 Vite build 通过，1440px、1024px、390px 无溢出或遮挡。
