# K 线光标日期格式设计

## 问题

图表只设置了 `locale: 'zh-CN'`，Lightweight Charts 仍使用默认日期模板 `dd MMM 'yy`。十字光标跨月时因此显示为 `04 8月 '26`，不符合中文交易终端习惯。

## 设计

- `localization.dateFormat` 固定为 `yyyy-MM-dd`，十字光标日期统一显示完整 ISO 交易日，例如 `2026-08-04`。
- 保留普通横轴的自适应刻度，例如“7月 / 16日”；不强制每个刻度显示完整日期。
- 不使用浏览器本地日期生成业务日期，不改动行情日期、时区、接口或图表数据。

## 验证

组件测试锁定传给 Lightweight Charts 的 localization 配置，实际页面检查蓝色光标标签，并运行全量测试与生产构建。
