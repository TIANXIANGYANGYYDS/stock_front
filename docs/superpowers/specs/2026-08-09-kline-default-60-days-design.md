# K 线切股默认 60 日设计

## 根因

后端 `/api/v1/stocks/{code}/daily` 已返回 120 根有效 K 线。前端手动导航后把 `windowSize` 设为 `null`，切换股票时没有重置；新图创建阶段执行 `Math.min(null, bars.length)` 得到 0，因此只显示最后约 1–2 根蜡烛。

## 设计

- 默认窗口常量为 60 个交易日，初次进入与每次股票代码变化都回到 60 日。
- 新图创建时即使上一个股票处于手动导航模式，也使用 60 日作为安全初始窗口，避免一帧的极端放大。
- 周期按钮保留 10、20、30 日并增加 60 日；默认高亮 60 日。
- 重置按钮恢复 60 日；手动 `− / + / ← / →` 后仍取消周期高亮，直到选择周期或切换股票。
- 不补造 K 线；不足 60 根时展示接口实际返回的全部有效 K 线。

## 验证

组件测试复现“手动导航后切股”，断言新股票重新高亮 60 日并设置正确逻辑范围；同时保留 API 请求 120 根历史数据的既有测试。运行全量测试、构建和实际页面检查。
