# 整站视觉重设计 · 2026-09-05

本次将五个工作区统一为浅色研究工作台，同时提供可持久保存的石墨深色模式。重点是内容层级、数据可读性和一致的导航与操作反馈。后续按反馈完成了[紧凑表格与 CSS 光效](2026-09-05-table-density-and-effects.md)，替换本次初版的横向宽表方案。

## 参考与取舍

- [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)：参考弱化导航、减少边框干扰、统一页头与内容区域的方式。
- [Vercel Geist 色彩系统](https://vercel.com/geist/colors)：参考背景、控件、交互状态及文字的语义分层；拉开正文与次级数据的层级。
- [shadcn/ui Blocks](https://ui.shadcn.com/blocks)：参考现代应用的侧栏、数据卡片和表格组合。
- [Apple Liquid Glass 介绍](https://developer.apple.com/videos/play/wwdc2025/219/)：仅在固定操作区使用轻量半透明材质，数据正文保持实色背景；网页实现为 CSS 材质，不是原生 Liquid Glass。

这是一套适合现有投研业务的综合设计，不复刻上述产品。保留红涨绿跌的 A 股语义。采用本地打包的 Geist / Geist Mono 处理西文和数字，中文使用系统字体。

## 实现边界

- 本轮不修改 API 请求契约、日期语义、计算口径或业务数据映射；不引入演示数据。
- 主题通过 `useAppearance.tsx` 管理；浏览器存储不可用时仍可正常切换。
- 图表主题仅调用 `applyOptions` 更改绘制样式，不重建图表、不重写行情数据、不重置窗口及指标。
- `studio.css` 作为最后加载的视觉层，统一语义变量并重排现有组件。布局断点与博主目录的 960px、资讯阅读的 1125px 条件保持一致。
- 盘前主线详情采用现有 Radix Dialog，支持 Escape、焦点约束与关闭后回到原入口。
- 支持键盘焦点、减少动态效果设置；手机保留底部安全区，宽表格在局部横向滚动。
