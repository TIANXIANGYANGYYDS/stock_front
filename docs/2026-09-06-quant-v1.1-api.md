目录为 `GET /api/v1/quant/strategies`。下面接口均使用目录选定编号组成 `/api/v1/quant/strategies/{strategy_id}` 前缀：

| 路径 | 页面使用 |
| --- | --- |
| `/overview` | 账户总览、数量统计、策略参数、成交约定、记录来源、运行信息与时间线 |
| `/performance` | 累计收益率、总资产、累计盈亏三种曲线；完整加载分页后按交易日升序 |
| `/accounts` | 全部逐股账户；股票、持仓与空仓筛选 |
| `/observations` | 观察方向、通用／细分状态、原因、数据时点与指标确认详情 |
| `/signals` | 信号、细分状态、原因、成交字段与执行尝试详情 |
| `/executions` | 当日模拟成交、费用与成交价格依据 |
| `/holdings` | 建仓、含费成本、估值、毛／净收益、账户当日收益和可卖状态 |
| `/closed-trades` | 所选交易日平仓；买卖信号价、参考价、成交价、费用与毛／净收益详情 |
| `/preselections` | 买入预选、参考价格、原因、状态及筛选 |
| `/sell-candidates` | 卖出候选、参考价格、原因与状态 |
| `/exit-decisions` | 持有、延期、退出判断；时点、前后状态、动作、指标、估算净收益与数据异常 |
| `/daily-results/{trade_date}` | 按需读取完整快照，切换九种业务列表；切换列表不重复下载 |

总览与完整快照读取 `response.data`；分页直接读取根对象的 `items`、`total`、`page`、`page_size`、快照元信息，账户页额外读取 `available`。默认每页 50，最大 200。

## 数据语义与一致性

- 逐股账户包含未交易和空仓账户，数量直接读取接口。`available=false` 显示账本不可用；`has_position=null` 显示持仓状态待确认，不当成空仓。
- 通用观察 `state` 与信号 `status` 保持独立；细分筛选分别传 `state_detail`、`status_detail`。未知细分状态显示原代码和中性提示。
- 条件满足、连续确认、信号状态与模拟成交分开展示。`attempt_count` 为累计次数，`attempts.length` 为已保存明细条数，二者不互相代替。
- 金额为人民币元、价格元/股、数量股；所有收益率只换算一次。0 正常显示，null 显示“—”。毛／净、累计／当日、全账户／单股账户／单笔持仓范围明确区分，不重算收益、不重复扣费。
- 退出判断标明估算收益与已实现收益不同。补录计算时间和运行阶段时点不作为成交时间。正式收益曲线从 2026-09-03 起，不补造缺失记录。
- 总览先返回实际日期和快照编号，列表随后固定二者。切换筛选、日期、策略会清理旧分页并取消过期请求。409 统一刷新总览，最多自动恢复一次；继续冲突则暂停并提供手动刷新。
- 普通最新页面沿用一分钟总览检查；完整记录页面按需读取，包含 `/quant/daily/latest`，不跟随轮询下载全部账户。卸载和失效请求会取消。
- 策略身份以目录为准，复杂详情只显示契约字段，嵌套策略身份使用公开值。未新增导出或原始响应调试输出，测试样本仅由测试文件引用。
