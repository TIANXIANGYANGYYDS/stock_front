# Motion 交互增强 · 2026-09-05

用户允许使用动画库后，查阅 Motion 与 GSAP 官方文档，选择项目已安装的 `motion@12.23.24`，接入 React 交互。使用当前依赖支持的 API，没有升级依赖或增加第二套动画引擎。

## 用户可见变化

- 主导航、量化子导航、博主目录、阅读标签和部分筛选项使用共享选中标记，通过弹簧过渡连接前后位置。文字和按钮点击区域保持稳定，手机底部导航也适用。
- 工作区与量化子页面切换时使用 280ms 淡入。动画仅随页面身份变化触发，量化快照和行情数据更新沿用原有组件行为。
- 切换博主作品、分析/原文时，当前内容立即替换，并短暂淡入；核心摘要有轻微位移。没有为退出动画保留另一份旧分析或图表。
- 新闻标题、正文与 AI 影响分析分别进入，最大额外延迟为 70ms。完整文本与数值始终保留。
- 博主筛选面板以 220ms 自动高度动画展开、收起；关闭中的表单设为 inert，并对辅助技术隐藏。重新打开保留筛选条件，不额外发起作品查询。

## 实现与回退

`StudioMotion.tsx` 集中管理动画、选中标记和折叠面板，`motion-features.ts` 独立加载 `domMax` 功能，轻量组件从 `motion/react-m` 导入，并通过 LazyMotion strict 避免混入完整 motion 组件。

动画模块未就绪或加载失败时，内容正常显示，筛选立即展开/关闭。系统“减少动态效果”设置变化会实时生效。沿用上一轮原生主题扩散与 CSS 阅读进度，去掉重复的工作区 CSS 入场效果。

本轮构建：主入口约 106.6KB gzip（此前约 78.1KB），动画功能文件约 15.8KB gzip。以上是实际项目构建结果，不是库宣传的最小体积。
