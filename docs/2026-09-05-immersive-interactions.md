# 3D 行情与指令中心 · 2026-09-05

针对用户希望看到更明显的前端技术表现，本轮增加可旋转、缩放、点选的行情场景，以及直接搜索股票和操作的指令面板。

## 体验入口

- 右上角 **3D 行情**：打开独立的全景阅读空间。拖动旋转、滚轮或双指缩放；鼠标经过或点选柱体时，名称标签、底部光环和右侧股票信息同步更新。股票列表同样支持键盘选择，点“打开 K 线分析”进入对应标的。
- **Ctrl / ⌘ + K** 或右上角查找按钮：打开指令中心，支持股票名称/代码、页面名称和常用操作。方向键选择，回车执行，Esc 关闭。搜索请求有去抖、取消及过期结果保护。
- 两个面板的边缘光线跟随鼠标位置，使用 CSS 遮罩绘制。保留系统鼠标和正常的文字选择方式。

## 数据含义

全景复用 `getStockList(tradeDate)`，展示所选交易日按成交额降序返回的前 50 只股票。界面明确标注日期和“前复权日线快照”。这些是该样本的行情分布，不代表全部市场的涨跌家数。

柱体高度按涨跌幅绝对值映射，红色上涨、绿色下跌；灰色底座表示平盘或数据缺失。缺失涨跌幅显示 `--`，真实零值显示 `0.00%`。收盘价、成交额和股票代码直接来自接口，不用插值动画展示金融数值。

股票跳转通过路由状态传递代码和请求标识，当前已经处于决策工作台时也能切换标的；原有搜索、行情获取、取消请求和 K 线逻辑继续工作。

## 实现

- 新增 `three@0.185.1` 与对应类型依赖。`market-scene.ts` 动态加载 Three.js、OrbitControls 和 Raycaster，首次进入普通工作区时不加载 3D 文件。
- 3D 场景有一次柱体进入动画；相机拖动使用惯性。仅在进入、交互或尺寸变化时绘制，空闲停止提交绘制命令，页面隐藏时停止安排新帧。复位视角先清空惯性，避免继续漂移。
- 关闭全景时释放几何体、材质、WebGL 上下文、监听器和 ResizeObserver。
- WebGL 不可用、上下文丢失或 3D 模块加载失败时，保留真实股票列表和 K 线入口。系统减少动态效果设置会禁用进入动画和惯性。
- 指令中心使用项目已有 `cmdk` 和 Radix Dialog，支持焦点恢复；已有其他业务弹窗打开时不会嵌套打开指令中心。
- 修复本地预览服务的旧模块缓存，并预优化 Three.js 依赖，避免开发环境首次打开全景时触发依赖优化重载。

生产构建中 3D 文件约 136.3KB gzip，独立于主入口；主入口约 115.0KB gzip。

## 验证

- 全量 41 个测试文件、235 项测试通过。新增缺失值与零值区别、等幅涨跌高度、接口排序/去重，以及外部股票跳转回归测试。
- 生产构建、项目类型检查和应用入口严格 TypeScript 检查通过。
- Chromium 连接真实后端显示 50 根对应股票的柱体，验证实际股票选择与 K 线代码一致、指令中心搜索 `600519` 及页面跳转。
- 通过鼠标拾取选中 10 个不同标的，检查名称标签、相机旋转与复位。监测 WebGL 绘制调用，确认停止交互后不再绘制。
- 模拟上下文丢失和禁止 WebGL，验证释放画布、保留列表与 K 线操作；验证减少动态效果设置。
- 检查 320、390、720、959、1024、1280、1600px 下的页面和新增入口，均无页面横向溢出；手机全景可纵向阅读。验证 Esc 和焦点恢复，无浏览器运行时错误。
